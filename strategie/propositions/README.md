# Propositions à étudier

Déposer ici les idées marketing qui ne sont pas encore validées. Pour chaque proposition, résumer le besoin, le bénéfice attendu, le coût ou les risques possibles, la façon de la tester et les critères de décision.

Ne pas multiplier les fichiers tant qu’il n’y a pas de proposition concrète à documenter.
