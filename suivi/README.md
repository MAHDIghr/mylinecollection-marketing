# Suivi des tests et des résultats

Ce dossier contient un tableau de suivi simple et les bilans périodiques.

Pour chaque test, noter autant que possible :
- produit et canal ;
- date de publication et prix ;
- contenu ou angle testé ;
- vues, visites et questions ;
- commandes payées et chiffre d’affaires ;
- coûts et marge estimée ;
- retours ou problèmes de qualité ;
- décision et prochaine action.

Les données disponibles varient selon les canaux. Inscrire « indisponible » si une mesure n’est pas fournie plutôt que de l’estimer arbitrairement. Ne pas décider d’un réapprovisionnement sur une seule vente ou sur les vues uniquement.
