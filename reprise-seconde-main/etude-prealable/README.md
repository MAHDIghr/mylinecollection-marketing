# Étude préalable — reprise des anciens sacs

**Statut : à étudier ultérieurement. Aucune implémentation immédiate n’est décidée.**

Utiliser ce dossier pour étudier la demande, le parcours client, les critères d’acceptation, les coûts de transport et de traitement, les débouchés (revente individuelle ou lots), les risques, les obligations applicables et la rentabilité globale. Documenter les hypothèses séparément des faits vérifiés. Ne lancer un pilote qu’après une décision explicite fondée sur cette étude.
